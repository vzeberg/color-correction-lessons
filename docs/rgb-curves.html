RGB-кривые и нейтрализация оттенков

Понять направления цветных каналов и использовать их как отправную точку для экспериментов.

Главное в этой теме

  • Подъём канала усиливает его вклад в выбранных тональных значениях; опускание ослабляет.
  • Цифровые противоположности: красный ↔ циан, зелёный ↔ маджента, синий ↔ жёлтый.
  • Нежелательный оттенок сначала локализуют и оценивают, затем корректируют умеренно.

Как цвет складывается из трёх каналов

Сначала понять механизм

Один цвет — три значения

У экранного RGB-образца есть три компонента: Red, Green и Blue. На нейтральном сером их значения равны. Изменим одну компоненту, сохранив две остальные.

Здесь показаны заданные экранные образцы. Это не смешение красок и не готовые настройки для фотографии.

Кривая действует на значение канала. Если у кожи и стены одинаковое значение Green, глобальная кривая Green изменит оба участка, даже если предметы выглядят разными по цвету. Для отдельной области нужна маска.

Тренажёр: каналы и тональные диапазоны

Красный↔Циан
Зелёный↔Маджента
Синий↔Жёлтый

Это модель RGB/CMY для коррекции изображения. Она отличается от художественного круга RYB, которым объясняются схемы Иттена в практикуме.

Тренажёр 1 · один шаг за раз

Двигайте кривую и следите за образцами

Начните с одного канала. Затем перенесите опорную точку из полутонов в тени или света: форма графика и изменение образцов будут пересчитываться вместе.

Сначала меняйте один канал, чтобы связать движение графика с видимым результатом.

Все каналы на диагонали: образцы остаются нейтральными.

Что проверить. При +R в тенях тёмные образцы станут краснее сильнее светлых. При −G в полутонах серый образец уйдёт к мадженте. Соседние значения тоже меняются: опорная точка не создаёт жёсткую границу.

Учебная модель: три точки соединены отрезками, крайние точки закреплены. Числа 0–255 описывают экранные RGB-компоненты; они не являются значениями ползунков Lightroom. Сглаживание и обработка RAW в редакторе отличаются.

Шесть направлений эксперимента

Допы к уроку:

1.Теплый золотистый оттенок:
- Красная кривая: Поднимите для усиления теплоты.
- Зеленая кривая: Легкое повышение для добавления золотистости.
- Синяя кривая: Опустите, чтобы противодействовать холодным тонам.

2. Осенний эффект:
- Красная кривая: Поднимите для усиления красных и оранжевых тонов.
- Зеленая кривая: Опустите немного, чтобы приглушить зеленый и подчеркнуть оранжевые тона.

3. Пастельные тона:
- Красная кривая: Слегка поднимите для мягкости.
- Зеленая кривая: Также слегка поднимите для деликатности зеленого цвета.
- Синяя кривая: Немного опустите для уменьшения синего и добавления тепла.

4. Ретро стиль:
- Красная кривая: Поднимите для придания изображению благородства.
- Зеленая кривая: Немного опустите для "выцветшего" вида.
- Синяя кривая: Слегка опустите для добавления желтизны.

6. Драматический/Кинематографический эффект:
- Красная кривая: Слегка поднимите для усиления драматизма.
- Зеленая кривая: Можно оставить без изменений или слегка поднять для добавления контраста.
- Синяя кривая: Поднимите для создания холодного, кинематографического фона.

7. "Холодное утро":
- Красная кривая: Незначительно опустите для уменьшения красного.
- Зеленая кривая: Слегка поднимите для усиления зеленых тонов.
- Синяя кривая: Значительно поднимите, чтобы добавить холодные сине-голубые оттенки.

Как подойти к нежелательному оттенку

Памятка по нейтрализации цвета

Главное правило

Для ослабления нежелательного оттенка часто полезно смещать цвет в противоположном направлении цифровой модели RGB/CMY.

Начните с такой последовательности:

  1. Найдите участок изображения с нежелательным оттенком.
  2. Определите, какой цвет преобладает.
  3. Добавьте противоположный цвет, чтобы вернуть цветовой баланс.

Например, если кожа приобрела зелёный оттенок из-за отражения травы, необходимо добавить пурпурный (Magenta). Зелёный и пурпурный являются противоположными цветами, поэтому они взаимно нейтрализуют друг друга.

Шпаргалка

Если участок на изображении слишком:

Жёлтое → добавьте синий.
Синее → добавьте жёлтый.
Красное → добавьте голубой (Cyan).
Голубое (Cyan) → добавьте красный.
Зелёное → добавьте пурпурный (Magenta).
Пурпурное / малиновое (Magenta) → добавьте зелёный.

Тренажёр 2 · нежелательный зелёный рефлекс

Убрать оттенок и проверить область воздействия

В этой схеме лицо и заведомо нейтральная карта получили зелёный рефлекс. Растение зелёное по своей природе. Сравните коррекцию всего кадра с коррекцией только выбранной области.

Сначала сравните карту с нейтральным серым. Кожу не нужно автоматически делать серой или приводить к одному оттенку.

  1. Найдите опору. Нейтральная карта должна быть нейтральной; зелёное растение — нет.
  2. Определите направление. Избыток Green на карте подсказывает движение к мадженте.
  3. Проверьте малое изменение. В примере опорная точка G перемещается из (156, 156) в (156, 132).
  4. Посмотрите на остальной кадр. Глобальная кривая меняет и другие значения G. Если они не требуют коррекции, ограничьте область.

Трёхточечная учебная кривая G, а не точная обработка Lightroom. Карта в примере нейтрализуется; после этого оттенок кожи всё равно оценивается отдельно. Возможность использовать кривые и сочетание локальных инструментов зависят от редактора и его версии.

Одно направление — разные последствия

«Снизить G» и «поднять R + B» не одинаковы по светлоте

Сравнение заданных образцов в одной опорной точке. Направление цветовой компенсации похоже, а выходные значения отличаются. Проверяйте цвет и светлоту вместе.

Уточнение для самостоятельной работыНачните с маленького изменения и сравните с исходником. Для смешанного освещения часто нужно ограничить область коррекции. Потерянный спектр источника или клиппинг не всегда исправимы добавлением противоположного цвета.

Проверить понимание на трёх примерах

Самопроверка

Объясните результат до движения ползунка

Что произойдёт с серым образцом, если опустить Blue?

Относительно усилится жёлтое направление. Это не означает, что инструмент выбрал только синие предметы.

Почему при коррекции зелёного лица поменялось синее пальто?

В синем пальто тоже есть компонент Green. Глобальная кривая этого канала может изменить его значения. Проверьте маску или другой способ ограничения области.

Почему «лавандовый» не получился на тёмном исходнике?

Светлый лавандовый требует соответствующей светлоты и насыщенности. Направление RGB — только одна часть результата.
