## Читать без интернета

Скачайте [HTML урока](https://github.com/vzeberg/color-correction-lessons/raw/refs/heads/main/docs/color-guide.html) и откройте его в обычном браузере. Стили, иллюстрации и тренажёры встроены в файл. Интернет понадобится только для перехода по справочным ссылкам.

## Как устроено размещение

- `docs/index.html` — каталог уроков.
- `docs/color-guide.html` — первый урок, с заголовком в две строки.
- `docs/.nojekyll` — служебный файл GitHub Pages.

GitHub Pages публикует папку `docs` из ветки `main`. После добавления или правки урока и отправки изменений в эту ветку сайт обновляется автоматически. Новые уроки добавляются отдельными HTML-файлами и ссылками в каталог.

Учебные пояснения подготовлены по предоставленным материалам курса. Схематичные иллюстрации и интерактивные примеры служат для разбора цветовых отношений; числовые значения тренажёров не являются готовыми настройками фоторедактора.
