## Как пользоваться

- На главной можно искать по тексту всех учебных разделов и заданий.
- На странице темы — содержание, связанные записи, практика, заметки и переходы дальше.
- Отметки, закладки, самооценка и заметки сохраняются в localStorage этого браузера; на сервер не отправляются.
- Каждая HTML-страница содержит свои стили и сценарии. Для чтения сохранённого комплекта без интернета оставьте файлы в одной папке. Записи и внешние ссылки требуют сети.

Номера 1–3 относятся к занятиям преподавателя; тематические дополнения не получают выдуманной исходной нумерации. Тексты сопровождают записи и не являются расшифровками видео. Для ряда материалов исходник содержит только общую папку Drive; отсутствующие вложения перечислены отдельно. Точечные технические уточнения отмечены на страницах и снабжены источниками.

GitHub Pages публикует `docs` из ветки `main`. Существующая ссылка `color-guide.html` сохранена.
